# 牌伴 PAIWISE

公开的游戏陪伴交互原型，包含游戏模拟与用户后台两个主界面。

## 模拟对局

- 三国杀：五人标准身份局原型，详见下方规则范围。
- 斗地主：已有的三次出牌决策教学片段。
- 掼蛋：普通对子跟牌与让牌练习，不包含升级和完整结算。
- 麻将：三次摸打一张练习，不包含吃碰杠与胡牌计算。
- 杀戮尖塔：简化能量、攻击、格挡和敌人意图战斗，不包含遗物或地图。
- 国际象棋：八条三回合开局分支，合法预设走法，黑方自动回应。
- 其他游戏：自定义名称的通用资源回合沙盘，不代表该游戏真实规则。

所有模拟提供手动操作、自动播放/暂停、重新开始、结束反馈与后台记录。自动播放不计入手动出牌偏好。三国杀使用独立五人规则引擎，其他教学游戏复用轻量状态转换框架。刷新页面重置进行中的模拟；决策记录与偏好保存在浏览器，按游戏隔离。

这是简化教学原型，不是完整官方游戏。建议由固定规则生成，不代表最优策略。

## 本地检查

运行 `node tests/simulation.test.cjs` 检查终态、资源、非法动作和棋盘分支；运行 `python3 -m http.server 4174` 预览静态页面。

GitHub Pages 从 main 分支根目录自动发布。本站没有部署模型后端，真实问答不开放。API 密钥和本地配置不属于此仓库。每位访问者的数据仅在各自浏览器保存，不共享。

## 五人三国杀与语言切换

三国杀升级为五人身份局：1 主公、1 忠臣、2 反贼、1 内奸。四个电脑玩家自动按座次行动，遇到你的响应会等待。支持新建对局、选身份/武将、多选手牌、选目标、手动出牌、暂停、托管、身份胜负和淘汰后观战。其他身份仅在阵亡或结算时公开，模型上下文不含其他玩家的手牌或隐藏身份。

独立规则引擎 `sanguosha-engine.js` 支持摸牌/出牌/弃牌、距离、基础牌、标准锦囊、装备、判定、无懈响应链、濒死求桃、击杀奖惩。首批武将为孙权、刘备、关羽、张飞、吕蒙，包含制衡、仁德、武圣、咆哮、克己与主公技。主公额外 1 点体力。104 张牌的种类数量采用标准包配置，花色/点数为原型配置，尚未实现全部标准武将；没有在线多人对战，不是完整官方客户端。

右上角 English / 中文 按钮切换界面语言，刷新后保留。牌桌、游戏库、用户后台及规则提示均支持英文。用户输入的偏好、问题和模型回复保持原文。语言切换不改变规则、局面、偏好或出牌历史。

运行 `node --test tests/*.test.cjs`：覆盖旧游戏引擎、100 场五人对局、牌数守恒、隐藏信息过滤、非法动作、距离、技能、濒死与结算。
